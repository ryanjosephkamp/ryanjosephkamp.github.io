Splashery

Splats you can play with.

A toy box of 3D Gaussian splats that runs entirely in the browser. Pick a toy, spin it, poke it, splash paint on it, drop it, watch it fall apart and come back, then share it as a link, a GIF or a video.

WebGPU, with WebGL2 fallback · no build step, no framework, no server

Play Source

grooph

Loop graphs for coding agents.

Draw who builds, who checks, where a person decides and when the work stops. grooph checks that every loop names a stop, then compiles the graph into a prompt package for Claude Code. It never runs an agent and never calls a model.

TypeScript · built for a phone · works offline

Open the app Docs Source

Ars Magna

An anagram of “Anagrams.” Also Latin for the great art.

Give it any text. It returns every way those exact letters can be re-partitioned into real English words: spaces move freely, every letter is used exactly once, nothing is added and nothing is dropped.

TypeScript · deterministic search · no AI

Try it Source

Amordle

Wordle + Hurdle + Lichess − ads.

A free word game with any word length from 2 to 35 letters, three difficulties, a daily puzzle, and ranked multiplayer against other people with a real Elo rating attached. No ads, no paywalls.
