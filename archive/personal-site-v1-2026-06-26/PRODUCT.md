# Product

## Register

brand

## Users

Visitors to Ryan's public personal website who want to understand his projects,
writing, CV, external profiles, and public GitHub work.

## Product Purpose

The website is Ryan's flagship public portfolio surface. It should present a
memorable, interactive, and claim-safe view of his work while linking clearly to
the blog, CV, GitHub profile, selected projects, and repository explorer.

Success means a visitor can quickly understand who Ryan is, move into the
repository graph for deeper project exploration, and reach supporting materials
without the homepage becoming a dense technical dashboard.

## Brand Personality

Polished, curious, and research-minded.

The site should feel visually compelling and custom, with a serious but
imaginative research-software atmosphere. It should show taste through real
interactive work rather than through inflated claims.

## Anti-references

The site should not feel like:

- a generic academic CV page,
- a generic SaaS landing page,
- an S26 AIRP-only site,
- a commercial or scientific hype page,
- a noisy animation demo that hides the content,
- or a page that implies scientific validation where only prototype work has
  been presented.

## Design Principles

1. Make the first viewport memorable without sacrificing readability.
2. Let the repository graph and real project surfaces carry the wow factor.
3. Keep the homepage personal and concise; send heavier exploration to the
   repositories page.
4. Preserve disclosure-first, non-overclaiming language around provisional
   scientific or domain-specific content.
5. Keep the personal website and blog related but distinct: the website is the
   flagship visual portfolio, and the blog can remain a simpler writing archive.

## Accessibility & Inclusion

Preserve strong desktop and mobile readability, visible keyboard focus states,
adequate color contrast, no page-level horizontal overflow, and support for
reduced-motion preferences. Interactive visualizations should keep accessible
fallback content, including the repositories page list/table view.
